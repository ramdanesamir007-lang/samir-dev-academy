Do I need any programming experience?

No. Programming Foundations starts with the basics. You only need a computer, a web browser, and time to practice. Other paths list their prerequisites so you can choose a suitable starting point.

Which learning path should I choose?

Start with Programming Foundations if you are new to coding. Choose Front-End Development for websites and interfaces, Back-End Development for data and APIs, or Full-Stack Development to connect both sides.

How should I follow the lessons?

Work through modules in order, run each example, and complete the exercise before moving on. Change the examples to check your understanding. Each course includes short lessons, code examples and knowledge checks. Complete a check to save your lesson progress in this browser.

Can I enroll in a course now?

You can start any course without an account. Lesson progress is saved on this browser and device. Account enrollment, payments and cross-device synchronization are not available.
